# Chapters & Passports — Yosemite Weekend

Netlify-ready static website for the July 17–20, 2026 Yosemite itinerary.

## Publish through GitHub
Upload every file in this folder to the root of your GitHub repository. Replace the existing `index.html`, `styles.css`, and `main.js`. Netlify will redeploy automatically after the commit.

## Files
- `index.html` — website content
- `styles.css` — responsive luxury design
- `main.js` — mobile menu, animation, image fallback, persistent checklist
- `rush-*.jpg` — local Rush Creek Lodge images
- `netlify.toml` and `_redirects` — Netlify configuration

Yosemite images are loaded from National Park Service URLs and automatically fall back to a branded scenic treatment if the remote image is unavailable.
