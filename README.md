# Chapters & Passports — Yosemite Weekend

A Netlify-ready static website package.

## Publish through GitHub + Netlify
1. Delete the old ZIP files from the GitHub repository (optional, but recommended).
2. Upload the **contents of this folder** to the repository root. `index.html` must remain at the top level.
3. Commit the changes to the `main` branch.
4. Netlify will redeploy automatically.

## Expected structure
```
index.html
netlify.toml
_redirects
assets/
  css/styles.css
  js/main.js
  images/
```

## Editing
- Itinerary copy: `index.html`
- Colors and layout: `assets/css/styles.css`
- Mobile menu/checklist: `assets/js/main.js`
